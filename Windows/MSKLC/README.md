# MSKLC方案

使用`MSKLC`工具创建键盘映射以实现输入世界语中的“帽子字母”

## 安装`MSKLC`

前往微软官方下载与安装该工具：https://www.microsoft.com/en-us/download/details.aspx?id=102134

## 配置文件介绍

`*.klc`文件是`MSKLC`工具的配置存档文件，使用工具读取klc文件后编译后即可使用。

## 配置文件键位说明

### [eoklav.klc](./eoklav.klc)文件

使用`AltGr`键（`右Alt`键或`Ctrl+Alt`均可）加对应字母即可输入“帽子字母”

### [EPO.klc](./EPO.klc)文件

分别将`y`、`x`、`w`、`q`、`[`、`]`替换为了`ĝ`、`ĉ`、`ŭ`、`ŝ`、`ĵ`、`ĥ`
